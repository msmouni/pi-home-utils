# Pi-Home Utils

Pi-Home Utils provides common code shared by the Pi-Home embedded applications.

It contains reusable utilities and the **common display model** used by [pi-home-display](https://github.com/msmouni/pi-home-display) and [pi-home-lafvin-ui](https://github.com/msmouni/pi-home-lafvin-ui).

The goal is to keep common functionality and interfaces shared between Pi-Home components in one place.
